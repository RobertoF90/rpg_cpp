# Week 4 Topic 1: C-Style Arrays

## Concept

An array stores multiple values of the same type in one variable. Access by index (0-based).

```cpp
std::string enemies[4] = {"Rat", "Goblin", "Troll", "Dragon"};
int enemyHPList[4] = {10, 20, 40, 100};
```

Access: enemies[0] = "Rat", enemies[1] = "Goblin", etc.
