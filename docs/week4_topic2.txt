WEEK 4 - TOPIC 2: LOOPING THROUGH ARRAYS

Use a for loop to access every element in an array.

Example:
    for (int i = 0; i < 4; i++) {
        std::cout << enemies[i] << std::endl;
    }

- i starts at 0
- Loop runs while i < 4 (so i = 0, 1, 2, 3)
- enemies[i] accesses each element in order
