Topic 2: Looping Through Arrays

Use a for loop to access every element:

    for (int i = 0; i < 4; i++) {
        std::cout << enemies[i] << std::endl;
    }

i starts at 0. Loop runs while i < 4, so i = 0, 1, 2, 3.

Example - display each enemy with HP:

    for (int i = 0; i < 4; i++) {
        std::cout << enemies[i] << " - " << enemyHPList[i] << " HP" << std::endl;
    }
